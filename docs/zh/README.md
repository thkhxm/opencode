# PunkcodeAI 桌面端 - 用户指南

PunkcodeAI 是一个面向中文用户的 AI 编程助手桌面端。它在 opencode 框架上做了产品化改造，把模型调用全部走 PunkcodeAI Cloud 网关（基于 sub2api），开箱即用，不需要你自己管理 API Key、不需要绑卡、不需要科学上网。

- 界面：完整中文
- 模型：Claude / GPT / Gemini / GLM 等主流模型，由管理员统一接入
- 计费：账户余额制，预充值后按 token 消费
- 平台：Windows（macOS / Linux 后续推出）

---

## 1. 下载与安装

### 1.1 下载

最新构建产物：

| 平台 | 文件 | 大小 |
|---|---|---|
| Windows x64 | `PunkcodeAI-win-x64.exe` | 约 123 MB |
| macOS / Linux | 暂未发布 | - |

下载地址（找管理员要内部链接，公开发布前不提供 GitHub Release）。

### 1.2 Windows SmartScreen 首次启动

由于 v1 还没买代码签名证书，第一次双击 `PunkcodeAI-win-x64.exe` 会弹 Windows SmartScreen「Windows 已保护你的电脑」蓝色提示：

1. 点窗口中的「**更多信息**」（不是直接关闭）
2. 出现「发布者：未知发布者」+「**仍要运行**」按钮
3. 点「**仍要运行**」

之后启动就不会再拦。

> 如果你的 IT 部门用 Windows Defender 企业策略硬拦：请把 PunkcodeAI 加白名单（路径 `%LOCALAPPDATA%\Programs\PunkcodeAI\`），或要求 IT 临时放行。

### 1.3 安装位置

PunkcodeAI 采用 NSIS 安装包，默认装到：

- 程序：`C:\Users\<你>\AppData\Local\Programs\PunkcodeAI\`
- 数据：`C:\Users\<你>\AppData\Roaming\PunkcodeAI\`（聊天历史、登录态、缓存）

卸载：控制面板 → 程序与功能 → PunkcodeAI → 卸载。卸载**不会删除**数据目录，避免误删聊天历史；如需完全清理，手动删除 `Roaming\PunkcodeAI` 文件夹。

## 2. 首次使用

启动后界面分两步引导：注册账号 → 进入聊天。

### 2.1 注册账号

- 邮箱：随便填一个**唯一**的邮箱即可，**不会发验证邮件**（v1 暂未接邮件）
- 密码：≥ 8 字符
- 昵称：用于聊天历史显示

点「注册」后会自动登录，跳到首页。

> 想注册多个账号？登出后用不同邮箱再注册即可。同一邮箱只能注册一次。

### 2.2 等待管理员充值

注册后默认余额是 **0 美元**。你必须先让管理员充值，才能开始聊天。

充值方式见后文 §4。**充值前如果直接发消息**，会收到「余额不足」错误，无法发送。

### 2.3 选择模型

进入聊天页后，左下角有「模型」下拉。下拉里会出现管理员开放给你的模型清单，比如：

- `claude-3-5-sonnet-20241022`（推荐写代码）
- `gpt-4o-mini`（推荐快速答疑）
- `gemini-2.0-flash`
- 其他管理员配置的模型

> **下拉为空**？见 §5「常见问题」。

### 2.4 开始聊天

选好模型，输入框输入问题，回车发送。所有聊天功能与 opencode 原版一致：

- 多轮对话
- 代码块自动高亮 + 复制按钮
- 引用本地文件（`@filename`）
- Slash 命令（`/help` 查看）
- 长回复流式输出

## 3. 余额与扣费

### 3.1 余额显示

右上角的余额 widget 会显示：

```
$ 5.20 ≈ ¥37.5
```

- 美元数字：你账户实际余额
- 人民币数字：按当前汇率折算（仅供参考，结算单位以美元为准）

每次发完聊天，余额会立刻更新。

### 3.2 扣费规则

每条聊天的费用 = **上游 token 成本 × 计费倍率**。

- 上游 token 成本：模型供应商（Anthropic / OpenAI / Google 等）的官方计价
- 计费倍率：管理员在 sub2api Group 里配置（不同 group 不同倍率）

具体每条扣多少，可在聊天页查看（鼠标移到消息上会显示该轮的 token 数 + 费用）。

## 4. 充值流程

### 4.1 申请充值

1. 点右上角「**余额**」widget
2. 弹出框点「**申请充值**」
3. 填申请金额（USD），如 `10`
4. 备注（可选）：写明转账截图 / 用途
5. 提交

申请后状态变「等待管理员审批」。

### 4.2 等待管理员审批

PunkcodeAI v1 是封闭团队制：

- 你**线下**把对应金额转给管理员（具体打款方式由你团队定，如微信 / 支付宝 / 银行转账 / 加密货币）
- 管理员收到款后，到 sub2api 后台手动批准
- 批准后**你的余额会立刻 +N USD**，桌面端约 5 秒内自动刷新

> 急用可以联系管理员催。审批是人工动作，没有 SLA。

### 4.3 充值历史

充值申请历史在「余额」widget 弹出框内可看，每条显示金额、状态、提交时间、审批时间。

## 5. 常见问题（FAQ）

### Q1：模型下拉为空，没法选模型

**根因**：你的账号被管理员配置成「没有任何可用模型」。

**排查**：

1. 联系管理员确认你被加到了「**default user group**」（注册时本应自动加入，但管理员可能手动改了）
2. 管理员检查 default user group 是否挂了至少 1 个 channel
3. 管理员检查 group 的「**ModelsListConfig**」是否启用 + 有模型条目（这个配置决定桌面端能看到什么）

确认后请管理员**保存 group 配置**，桌面端**重新登录一次**（退出 + 登入）即可拉到。

### Q2：余额申请提交后一直「待审批」

**根因**：

- 你还没线下打款给管理员
- 管理员没看到邮件 / 微信 / 后台通知

**处理**：直接联系管理员催办。

### Q3：聊天报「Service temporarily unavailable」/ 「上游不可用」

**根因**：

- 上游 channel 的 OAuth token 过期（如 Claude 账号需要重新登录）
- 上游 channel 配置了 `restrict_models` 白名单，你选的模型不在白名单里
- 上游 channel 的代理（proxy）断了

**处理**：联系管理员检查 sub2api Ops → 错误日志，定位是哪个 channel + 修复。**临时绕过**：切换到另一个模型（用别的 channel 的话能正常工作）。

### Q4：聊天报「余额不足」但我刚充过

**根因**：管理员审批了申请，但桌面端余额没刷新。

**处理**：

1. 点余额 widget，强制刷新一次
2. 仍不对 → 退出登录再登入
3. 仍不对 → 联系管理员，对 `/cli/me` 接口查实际余额（sub2api 数据库才是 source of truth）

### Q5：升级与版本

**自动检查**：

- 桌面端启动时自动检查更新（5 秒后台触发）
- 有新版会在右上角通知「新版本可用」
- 点通知开始下载，下载完弹「立即重启安装」

**手动检查**：

- 顶部菜单 → 「检查更新」（macOS 下在 App 菜单，Windows 下在「**…**」溢出菜单）
- 弹「已是最新版本」或「发现新版本 X.Y.Z」

**禁用自动检查**：

- 设置 → 更新 → 关闭「启动时自动检查更新」

### Q6：聊天历史存在哪？怎么备份？

- 存在本地 `%APPDATA%\PunkcodeAI\` 下的 SQLite + JSON
- 备份：直接复制整个 `PunkcodeAI` 文件夹
- 多机同步：v1 不支持云端同步，要换电脑请把整个文件夹拷过去

### Q7：可以接自己的 API Key 吗？

可以但**不推荐**。PunkcodeAI v1 的核心价值是「不用管 API Key」，自带的 provider 连接界面（如果你能找到）是 opencode 原生残留，**已被产品策略隐藏**。

如果你确实有自己的 Claude / OpenAI 账号想用，建议直接用 opencode 原版（这是 PunkcodeAI 的上游开源项目）。

### Q8：哪些数据会被收集？

- **聊天内容**：经 PunkcodeAI Cloud 网关转发给上游模型，sub2api 会**记录请求日志**（含时间 / 模型 / token 数 / 费用），用于计费和排错；**不长期存储完整 prompt / response 内容**（仅短期日志 + 错误样本）
- **登录态**：邮箱 + 密码 hash 存在 sub2api postgres
- **遥测**：v1 默认**不上报**第三方遥测（PostHog / Sentry 等已关闭）

## 6. 故障反馈

报 bug 之前请准备：

1. PunkcodeAI 版本号：菜单 → 关于
2. 操作系统版本
3. 复现步骤
4. 日志：`%APPDATA%\PunkcodeAI\logs\main.log` 最后 200 行

联系方式：找你团队的 PunkcodeAI 管理员（不要直接发到 opencode 上游仓库）。
